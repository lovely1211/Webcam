# Webcam

## 📌 Overview
This project is a **Webcam Application** built using MERN-Stack, allowing users to capture images and videos from their webcam in real time.

## 🚀 Features
- Access webcam using browser
- Capture images & videos instantly
- Display captured images or videos on the screen
- Simple and user-friendly interface

## 🛠️ Technologies Used
- MongoDB
- React.js
- Express.js
- Node.js
- CSS3

   ## 📥 Installation & Setup
1. **Clone the repository:**  
   ```bash
   git clone https://github.com/lovely1211/Inner-Glow.git
   ```
2. **Navigate to the project directory:**  
   ```bash
   cd Inner-Glow
   ```
3. **Navigate to the backend:**  
   ```bash
   cd backend
   ```
4. **Install dependencies:**  
   ```bash
   npm install
   ```
5. **Start the development server:**  
   ```bash
   npm run dev
   ```
6. **Navigate to the frontend:**  
   ```bash
   cd frontend
   ```
7. **Install dependencies:**  
   ```bash
   npm install
   ```
8. **Start Script:**  
   ```bash
   npm start
   ```

## 📸 How to Use
1. Allow webcam access when prompted.
2. Click the **📸** button to take a snapshot.
4. The captured image or videos will be displayed below.
5. Captured files can be saved or deleted.
6. Saved files store in seperate gallary page.
